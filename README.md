# WindowsResetTool

Автономная утилита на Python для Windows 10/11, автоматизирующая безопасный запуск переустановки или сброса операционной системы до заводских настроек без использования загрузочной флешки.

## Как это работает
Программа взаимодействует с официальной средой восстановления Windows (**WinRE**) через утилиту `systemreset.exe`:
- **systemreset -factoryreset** — запуск мастера полного сброса (с выбором: сохранить файлы или удалить всё, загрузка из облака или локальная переустановка).
- **systemreset -cleanpc** — инструмент «Новый запуск» (Fresh Start).

Все действия производятся встроенными механизмами самой Windows, гарантируя целостность системы и безопасность процесса.

## Возможности
- Автоматическая проверка прав администратора и запрос повышения через UAC.
- Корректная обработка путей на 32- и 64-битных системах (`Sysnative` / `System32`).
- Двойное подтверждение в консоли для защиты от случайного запуска.
- Сборка в один автономный `.exe` файл без зависимостей.

## Сборка бинарного файла (.exe)
```powershell
pip install pyinstaller
pyinstaller --onefile --uac-admin --clean --name "WindowsResetTool" reset_windows.py
```
Скомпилированный файл будет находиться в директории `dist/WindowsResetTool.exe`.
